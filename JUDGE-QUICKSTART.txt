CoreWarden Windows quickstart
=============================

Originally prepared for hackathon judges; retained as the packaged quickstart.

1. Extract the entire CoreWarden folder from CoreWarden-Windows-x64.zip.
2. Launch CoreWarden.exe. Because this build is unsigned, Windows SmartScreen may ask
   you to confirm that you trust it.
3. Choose OpenAI or Bedrock.
   - OpenAI: paste your project API key and select Save securely. CoreWarden stores it
     in your Windows Credential Manager and clears the entry field.
   - Bedrock: authenticate an AWS profile/session with Bedrock access, then enter its
     profile and region. CoreWarden does not store AWS secrets.
4. Enter the URL and authentication for a running local Core-compatible node. Use
   either RPC username/password or its cookie file; CoreWarden does not save them.
   The default http://127.0.0.1:8337 is for Bitcoin II. Change it for another node
   or network; CoreWarden does not detect the chain or choose its port.
5. Select Test Provider, then Test Node, then Run Diagnosis.
6. Read the classification, confidence, evidence, and safety boundary in the result.
7. Optional: choose an interval (5 minutes by default) and select Start Monitoring.
   Deterministic local checks run on each cycle. AI runs only for a new or materially
   changed degraded condition; unchanged conditions are deduplicated.

Privacy: CoreWarden calls only getblockchaininfo, getnetworkinfo, getpeerinfo, and
getchaintips. Peer-identifying and endpoint data is filtered locally before model
access. Raw RPC credentials and peer-identifying observations are not intentionally
persisted.
Monitoring is read-only and off by default. Sanitized monitoring history is stored
locally (up to 1000 events); the recent-event panel shows up to 20 entries. While
monitoring, closing the window hides it to the tray; use Quit CoreWarden to exit.
